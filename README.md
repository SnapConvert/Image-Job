## Overview

**ImageJOB** is a free, open-source raster graphics editor designed as a modern, high-performance alternative to proprietary software like Adobe Photoshop. Built from the ground up by creators for creators, ImageJOB aims to deliver a familiar user interface alongside enterprise-grade image processing powers without subscription fees, telemetry, or walled gardens.

### Why ImageJOB?

> *"Creative tools should empower artists, not tie them to recurring monthly costs."*

- **100% Free and Open Source:** ImageJOB is licensed under GNU General Public License v3.0, ensuring it remains free forever for personal, commercial, and educational use.
- **Familiar Workflow:** Transition seamlessly with an interface layout, shortcut mapping, and core workflow inspired by industry-standard design tools.
- **Privacy First:** No mandatory cloud sign-ins, tracking, or data harvesting. Your files and work remain entirely on your local machine.
- **Performance Focused:** Written with modern C++ and GPU acceleration via Vulkan/Metal, ImageJOB delivers high-frame-rate canvas panning, real-time brush previews, and fast rendering.

---

## ✨ Key Features

- 🎨 **Advanced Layer Management:** Full support for non-destructive layer masks, adjustment layers, smart objects, blend modes, and hierarchical grouping.
- 🖌️ **Custom Brush Engine:** Dynamic brush settings including tilt/pressure sensitivity, custom texture tips, dual brushes, and procedural stroke smoothing.
- ⚡ **Non-Destructive Editing:** Non-destructive filters, live smart filters, and full 32-bit float channel depth support for high-dynamic-range (HDR) editing.
- 📐 **Vector & Typography Tools:** Integrated vector paths, shape layers, text tool with full OpenType feature support, and text-on-path capabilities.
- 💻 **Cross-Platform:** Native support across Windows, macOS (Intel & Apple Silicon), and Linux distributions.
- 🔌 **Plugin & Scripting API:** Extend functionality with custom Python scripts or C++ native plugins.

## 🚀 Installation

### Windows
Download the latest `.exe` installer from the [Releases](https://github.com/imagejob/imagejob/releases) page and run the setup wizard.

### macOS
Download the `.app` file suitable for your architecture (Apple Silicon or Intel), open it, and drag **ImageJOB** to your `Applications` folder.

### Linux
ImageJOB is available as an AppImage, Flatpak, and Snap package:
